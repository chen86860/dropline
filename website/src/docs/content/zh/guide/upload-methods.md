# 五种上传方式

Dropline 有五个入口，每一个都在 macOS 早就放好你双手的地方。不管文件从哪儿进来，出去的方式都一样：链接落到剪贴板，再给你一条系统通知。

## 1. 窗口

打开 Dropline，把文件拖上去。窗口是唯一能看到完整队列的地方 —— 每个文件一行，各自带进度条，下面还有历史记录。

拖**文件夹**进来，Dropline 会展开它，把里面的文件传上去。

## 2. 程序坞图标

把文件拖到程序坞里的 Dropline 图标上，不用先打开应用。上传立刻开始，窗口不会被唤到前台。

如果你根本不想要程序坞图标，打开**设置 → 通用 → 隐藏程序坞图标（仅菜单栏）**。Dropline 就成了纯菜单栏应用，程序坞里没有它，⌘-Tab 里也没有。

## 3. 访达右键菜单

在访达里右键点任意文件，选**使用 Dropline 上传**。它在菜单的*第一层*，不用翻到「服务」里去找。

这来自一个访达扩展，macOS 在你手动批准前不会启用它 —— 见[安装](/zh/docs/getting-started/install#打开访达扩展)。**设置 → 通用 → 访达右键菜单**下有三种显示方式：

| 方式 | 效果 |
| --- | --- |
| 显示（带图标） | 菜单项旁边有一个上传图标 |
| 显示（不带图标） | 纯文字，和系统自带的菜单项风格一致 |
| 不显示 | 右键菜单里没有它；其它入口照常可用 |

改完立即生效，不用重启访达。

### 当作「服务」快捷键用

同一条命令会出现在**系统设置 → 键盘 → 键盘快捷键 → 服务 → 文件和文件夹**下，可以绑一个组合键。在访达里选中文件，按一下，完事。

## 4. 剪贴板

复制一张图，不落盘直接传。截图走这条路最快：按 `⇧⌘4` 框选区域 —— 按住 `⌃` 截图时 macOS 会把图放进剪贴板，或者在截图工具栏里选「拷贝到剪贴板」。

从浏览器、聊天窗口或者「预览」里把图弄出来又不想先存文件，也是走剪贴板。

## 5. 菜单栏

菜单栏图标才是这个应用真正的家。

- **上传…** 打开系统文件选择面板。
- **最近 5 条链接**就在菜单里，点一下就重新复制。
- 上传时图标**变成进度环**，不用切窗口就能看到整体进度。

## 传完之后

五个入口的收尾动作完全一样，每一项都是**[设置 → 通用](/zh/docs/guide/settings)**里的一个开关：

1. **链接落到剪贴板** —— 裸链接，或者打开「复制为 Markdown」后的 `![name](url)`。
2. **弹一条系统通知**，带上文件名。
3. **写入历史记录**，保留最近 300 条，其中最近 5 条出现在菜单栏里。

## 大文件与并发

任意文件类型都收。大文件（尤其是视频）从临时文件流式上传，不会整个读进内存，所以传两个 G 的视频和传一张截图占的内存是一样的。

上传是**并发**的，默认 3 个，可以在**设置 → 通用 → 并发上传数**里改成 1、2、3、5 或 8。单个文件的传输超时是一小时，慢网络和大视频不会被中途掐断。
