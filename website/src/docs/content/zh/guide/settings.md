# 设置项说明

用 `⌘,` 打开设置，或者从菜单栏图标进。一共三个标签页：**通用**、**图床**、**关于**。这一页讲通用和关于；[图床配置](/zh/docs/hosts/overview)单独成节。

## 通用

### 上传完成后把链接复制到剪贴板

**默认开启。** 这就是这个应用存在的理由。关掉之后上传照常进行、照常通知、照常进历史记录，只是得你自己去菜单栏或者历史列表里复制链接。

### 复制为 Markdown `![name](url)`

**默认关闭。** 依赖上面那个开关。打开后剪贴板里是

```text
![screenshot-2026-08-08.png](https://cdn.example.com/2026/08/a1f3c9.png)
```

而不是裸链接。alt 用的是原始文件名，不是远端的对象键。

### 上传完成后发送系统通知

**默认开启。** 一条标准的 macOS 通知，带文件名。第一次可能会请求通知权限；如果当初拒绝了又想要回来，去**系统设置 → 通知**里重新允许 Dropline。

### 隐藏程序坞图标（仅菜单栏）

**默认关闭。** 打开后 Dropline 变成纯菜单栏应用 —— 程序坞里没有图标，⌘-Tab 里也没有。注意这同时也去掉了「拖到程序坞图标上」这个入口；窗口、访达、剪贴板、菜单栏都不受影响。

### 并发上传数

**默认 3。** 可选 1、2、3、5、8。超出的文件排队，有空位就开始。网快、文件多可以调高；图床限流或者你想要确定的顺序，就调到 1。

## 访达右键菜单

### 显示方式

**默认「显示（带图标）」。** 控制访达右键菜单第一层的**使用 Dropline 上传**。

| 选项 | 行为 |
| --- | --- |
| 显示（带图标） | 在右键菜单顶部，带一个上传图标 |
| 显示（不带图标） | 在右键菜单顶部，纯文字 —— 和系统自带项一致 |
| 不显示 | 右键菜单里完全没有它 |

改完立即生效，不用重启访达。如果选了「显示」但菜单项根本不出现，那是扩展本身还没被批准 —— 见[安装](/zh/docs/getting-started/install#打开访达扩展)。

## 外观

### 配色方案

**默认「跟随系统」。**「浅色」和「深色」只覆盖 Dropline 自己，系统其它地方不受影响。「跟随系统」也包含系统里那档「自动」的日夜切换。

菜单栏图标是模板图，永远跟随菜单栏本身反色，不受这里影响 —— 这也是对的，旁边所有系统图标都是这个行为。

## 语言

### 界面语言

**默认「跟随系统」。** 非中文一律回落到英文。手动选择立即生效，不用重启；这个选择还会同步给访达扩展的菜单项。

## 软件更新

更新通过 [Sparkle](https://sparkle-project.org) 下发，用 EdDSA 签名，被篡改过的包装不上。

| 设置 | 默认 | 效果 |
| --- | --- | --- |
| 自动检查更新 | 开 | 后台定期检查 |
| 自动下载并安装更新 | 关 | 静默更新；依赖上面那项 |
| 立即检查 | — | 马上查一次，告诉你有更新还是已是最新 |

面板里还显示当前版本和上次检查的时间。更新说明有中英两份，跟着界面语言走。

## 关于

应用图标、版本号（可选中，方便粘进 issue 里），以及三个按钮：**检查更新…**、**项目主页**、**反馈问题**。

## 设置存在哪儿

| 内容 | 位置 |
| --- | --- |
| 各项设置与图床配置 | `~/Library/Preferences/dev.emmmm.Dropline.plist` |
| 上传历史（最近 300 条） | 同一个偏好设置文件 |
| 密钥 —— token、Secret Access Key | **系统钥匙串**，service 为 `dev.emmmm.Dropline` |

任何密钥都不会写进偏好设置文件。这个拆分是刻意的，详见[密钥与隐私](/zh/docs/guide/security)。
